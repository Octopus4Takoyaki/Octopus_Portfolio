Delivery Details04

交付细节

浏览器端交互
不只是一段模型调用

为了让工具能在不同招聘页中稳定使用，产品把交互触发、结构化渲染和失败状态一并纳入交付范围。

结构化渲染

直接消费模型返回的 JSON 字段，避免对象被误渲染为 [object Object] 或混入 Markdown 标记。

触发稳定性

使用 selectionchange 与防抖识别选区；以 all_frames: true 覆盖 iframe 中的 JD 场景。

明确失败状态

加入 25 秒超时和空返回拦截，避免请求异常时页面持续停留在加载状态。

跨站样式隔离

关键按钮采用内联样式，列表项目符号由自身 ::before 绘制，减少招聘网站 CSS 重置带来的显示问题。

Privacy & Scope05

BYOK 配置

密钥由用户管理
产品不设自建业务服务器

用户自行配置模型 API Key，密钥仅保存在浏览器本地存储。产品只将用户主动选中的 JD 文本和公司、行业提示发送至其选择的模型服务商；不收集浏览历史，不爬取招聘平台或面经数据。

当前支持

Chrome 与 Edge 共用同一套 Manifest V3 代码；产品目前以本地加载和 Edge 商店审核为主要发布状态。

当前边界

公司与行业识别为启发式判断，可由用户手动修正；grounding 主要依赖模型已有知识，实时联网检索与飞书推送尚未实现。

使用提示

生成内容基于公开信息与行业通识，不代表公司内部视角。用户应在面试或后续沟通中自行核实关键结论。

暂未适配

Firefox 与 Safari 尚未适配，历史记录与外部协作同步不在当前 MVP 范围内。
